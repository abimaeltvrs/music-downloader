# Music Downloader V1.3

Envie os arquivos e a pasta .github para a raiz do repositorio. Substitua os arquivos antigos (na interface web, edite os arquivos existentes individualmente se necessario). Execute Actions e baixe o artifact V1.3.

A primeira execucao do Demucs pode baixar um modelo de IA. O build nao garante funcionamento: teste no Windows. Se o Demucs falhar, a mensagem agora mostra a excecao real.

A aba Links usa yt-dlp somente para conteudo proprio ou com download autorizado, conforme as regras do site.

A edicao de cortes em Links ainda nao esta integrada: baixe o arquivo permitido e utilize Conversor para cortar.
